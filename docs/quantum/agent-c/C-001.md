## Explicit semantics

State is `|psi> = sum_i alpha[i] |i>`; array index bit `q0` is least significant; printed ket `|q[n-1] ... q0>`. `Statevector::zero(n,budget)` initializes `|0...0>`; `from_amplitudes` only accepts finite, unit-norm inputs. Zero qubits represent the scalar `|>` with one amplitude; all wire operations on it reject unknown qubits.

The implemented gates are H, X, Y, Z, S, T, CNOT, CZ, SWAP with validated targets and double-use prevention. No reset, dynamic feed-forward, arbitrary angles, arbitrary unitaries, channel, noise, pulse, QIR or OpenQASM. Global phases are retained in the full statevector; this crate makes no claims about formal equivalence modulo global phase.

Single-wire `measure(q,rng)` performs a probabilistic computational-basis observation, projects and renormalizes the state, **does not consume a language-level handle** and permits physically consistent repeated measurement. `postselect(q,outcome)` explicitly rejects zero-probability outcomes. `wire_probability` and `basis_probability` are analytic f64 calculations, *not Monte Carlo estimates*. `sample_basis(shots,seed)` produces independently drawn classical basis indices from the unchanged source state, **not** repeated measurements on a collapsed state. For statistical checks of a Bell state, the reference test uses 4,096 shots with a tolerance of 0.05 from 0.5; a priori standard deviation is 1/128 = 0.0078125 (6.4 standard deviations). This is not an exact 50/50 promise.

## Numerical and resource policy

All state amplitudes have f64 real and imaginary parts. `Complex::norm_squared` computes `re*re + im*im`; state norm uses a simple left-to-right IEEE-f64 sum. `NORM_TOLERANCE = 1e-10` applies to initialization, before/after gates and after projection. It is a **sanity threshold**, not a proven global error bound. The gate code uses the f64 representation of `1/sqrt(2)`; no bit-exact reference tensor, interval arithmetic, or platform-independent formal rounding certificate is claimed. NaN, Infinity, normalization mismatch and impossible postselection fail explicitly.

The dimension calculation uses checked shifts and checked byte multiplication. A configured logical allocation limit covers `2^n * sizeof(Complex)` for the state and additionally `shots * sizeof(usize)` for the requested shot vector; `try_reserve_exact` catches allocator refusals. The limit describes logical content and does not guarantee an OS allocator's metadata, foreign input Vec capacity or process-wide resident memory. Statevector memory is O(2^n) and sampling takes O(shots * 2^n); deliberately **not a scalable quantum advantage**. Default budget 16 MiB. Unsupported dimensions and over-budget requests return typed errors.

The seeded pseudo-random stream is explicitly **SplitMix64**, with wrapping u64 constants 0x9e3779b97f4a7c15, 0xbf58476d1ce4e5b9, 0x94d049bb133111eb; `next_f64` maps the upper 53 random bits to the half-open interval [0,1). This is a deterministic testing RNG, not cryptographically secure randomness. Reproducibility claims apply to the same engine version, algorithm and numerical environment. No hardware measurements.
