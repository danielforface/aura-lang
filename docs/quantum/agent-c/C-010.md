## BEFORE → AFTER (actual product behavior)

**BEFORE:** Pure and noisy CPU reference used floating-point `Complex f64`
and the Clifford stabilizer used exact binary Pauli tableau without
support for T/non-Clifford phase amplitudes. No engine could produce
**exact algebraic complex** probabilities or coherences for H/T
interference and then verify a selected measurement branch while
retaining an exact computable joint probability.

**AFTER:** a new standalone `src/symbolic.rs` engine represents a vector
in the algebraic ring `Z[√2,i]/2^k` by four signed checked
`i128` coefficients per complex entry and an
explicit bounded denominator. It supports all nine existing
H/X/Y/Z/S/T/CX/CZ/SWAP gate families, including T,
without **any floating-point amplitude update**.
It returns exact amplitude/coherence, exact computational-basis
joint probability, exact phase-sensitive equivalence of physical
rays by cross-multiplication and exact selective Z projection
by preserving the unnormalized vector.

**Important scientific distinction:** For postselected HTH, the
normalized conditional amplitude may lie *outside* this ring.
This engine **does not claim to have normalized that state**.
Instead each instrument trace records exact joint weights before
and after projection in `Q(√2)`. Their ratio is the **exact
conditional Born probability**. Only the convenient printed ratio
is approximate `f64`; no stochastic draws are made.

Rust public `SymbolicState` + `SymbolicCircuit`
can be invoked by a real application. `SymbolicCircuit` offers
explicit forced Z outcomes into a bounded classical register and
classically conditional gates, with complete validation of unreachable
branches before execution. An impossible outcome, aliased
two-wire gate, invalid bit, unsupported dimension, insufficient
memory, too many H/T operations or checked-integer overflow
**fail closed**.

## Versioned external real-callable API

`src/symbolic_json.rs` +
`src/bin/aura-quantum-symbolic-run.rs` expose a **separate**
strict JSON stdin/stdout contract:
`aura.quantum.symbolic-request/1` →
`aura.quantum.symbolic-result/1`.
Fixtures `symbolic_hth_v1.json` and
`symbolic_bell_forced_v1.json` exercise actual
Clifford+T interference and Bell postselection with conditional
X corrections. JSON coefficients are strings with sign and decimal
digits (not lossy JS numbers); display approximation fields are
consciously marked. Structured errors appear on stderr with exit 2
and no stdout success receipt. Result metadata contains
`evidence_class=simulation`, `qpu_hardware_jobs=0`,
`sampling=none;forced-outcomes-only`, exact ring/profile and
engine version. Existing pure/noisy/stabilizer JSON v1 protocols
remain wholly untouched.

Limits: at most 4 qubits (2^4 exact complex entries), 128
operations, <=48 H/T operations including unreachable branches,
<=16 classical bits, <=64KiB request, <=1MiB result, <=16MiB
admitted logical memory; time/RSS are **not** certified by budget.

  Python/NumPy implementation of the integer radical ring against
  independent complex dense arithmetic:
  `SYMBOLIC_PREFLIGHT_PASS` on **128 deterministic circuits**,
  **3,584 unitary operations**. The first locally detected mistake
  in the T-phase formula was fixed *before* Rust implementation.
  No local `cargo/rustc` is available; do not claim

- **Rust fixtures** `tests/symbolic.rs`:
  exact HTH `P0=(2+√2)/4,P1=(2−√2)/4`, exact
  relative phase coherence, global-ray tests, Bell sequential
  projection mass, conditional correction and analytic
  equivalence with the independent f64 Statevector subset.
- **Real user CLI fixtures** `tests/symbolic_json.rs`:
  exact JSON string transport, deterministic real subprocess,
  exact Bell branch weights, impossible branch negative,
  schema isolation, unsupported hardware/rotations/seed/shots
  rejection and finite resource guards.
- **Independent external numerical oracle**
  `tools/check_qiskit_symbolic.py` calls the built Rust
  executable for **64 unitary + 16 selective** 1–4 qubit
  Clifford+T circuits and compares *all 600 complex amplitude
  entries* against separately constructed Qiskit Statevector
  plus explicit unnormalized projector, with **80 mutation
  negative controls**. Pinned Python 3.11, Qiskit 2.6.1,
  NumPy 2.3.4. This is numerical independent parity,
  **not** mathematical soundness/completeness theorem proof.
- Existing scoped quantum CI runs all Rust tests, strict
  Clippy, runnable user applications, pure/noisy/stabilizer
  Qiskit parity and CPU scaling alongside the new symbolic
  profiles. Keep previous oracles active rather than resetting
  baseline functionality.
