# Agent C — C-017: analytic Pauli Hamiltonian energy variance

Delivery phase, Rust library slice. C-016 already computes the analytic mean of a Pauli Hamiltonian on a pure factor-product state. This phase adds a callable pure-state function to evaluate the second moment and variance, including anti-commuting Pauli products, Y phases and finite coefficients, with no shot sampling and no 2^128 allocation. The result is conditional on the actual state passed in. Measurement branches are not automatically averaged.

Mathematical identity: H=sum_i c_i P_i; E[H^2]=sum_i c_i^2 + 2 sum_(i<j,commuting) c_i c_j sign(P_i P_j) E[PauliProduct(i,j)]. Anti-commuting cross terms cancel in the Hermitian anticommutator. Variance=E[H^2]-E[H]^2. This is analytic operator algebra evaluated with finite-complex-f64 amplitudes, not a formal numerical error bound or a ground-state proof. A small negative cancellation residual within a scale-adjusted tolerance is clamped and flagged; a greater negative residual is rejected.

Boundaries: <=128 global wires, <=10 per factor, <=64 Pauli terms, finite real |coefficient|<=10,000, conservative <=16,777,216 arithmetic work units based on actual factor widths. One temporary signed Pauli word per commuting pair, no retained pair matrix, no QPU. A 128q / 64 Bell+T product is a running example. Tests include dense H|psi> independent oracle on complex 2-8q and rejection paths. Rust module is additive, no JSON v1 ABI/contract or older CLI change. A separate experimental versioned moments JSON CLI is included. Existing C-016 observable/1 and other direct-engine JSON schemas remain unchanged; downstream QIR/Aura adoption is D2 and requires consumer ACK.
