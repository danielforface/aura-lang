# Agent C — C-021 | Selective conditional local tomography

**Production BEFORE→AFTER:** C-020 provides *unconditional* final one-wire/selected two-wire reduced density matrices, Bloch XYZ and reduced purity for a bounded ideal dynamic quantum channel; users cannot ask “what is the state conditional on final classical measurements c0=1, c2=0?” without doing their own branch/accounting. C-021 adds **`execute_conditioned_tomography(circuit,pairs,conditions,budget)`**, returning final **Born-weighted conditional reduced states** and the probability of the selected final-bit event. Only requested condition bits are echoed. Individual instrument histories or classical distributions of unselected outcomes are NOT returned. Existing C-020 unconditional contract is preserved.

**Semantics:** A condition has (bit,equals); 1..64 distinct conditions in ascending bit index, only **explicitly measured** classical bits, not hidden reset outcomes. Conditions reference *final* registers: if a bit is measured twice, last value determines selection. The engine first runs shared C-018 `enumerate_channel` with all original instrument outcomes, gates and feed-forward, then selects branches whose final classical bits match. Let P(E)=Σ_b∈E p_b; conditional rho_S|E=Σ_b∈E[p_b/P(E)] Tr_not_S(|psi_b><psi_b|). A zero-probability condition returns `ImpossibleCondition`; probability below 1e-12 returns typed `ConditionProbabilityTooSmall` because f64 resolution here is not certified for extreme postselection. Missing/duplicate/unwritten/reversed/out-of-range bits fail closed. No branch history is logged or persisted; transient internal branch enumeration still uses bounded memory. **The condition itself and its probability are explicitly returned**, since conditioning cannot be interpreted without them; there is no full classical histogram.

**Physics:** Local mixed purity is not a formal entanglement certificate. Branch mixing gap is recalculated *within the selected event* and can remain positive when unselected measurement bits are not conditioned. Bell measurement conditioned on c0=1 produces |11> pure pair with probability 1/2; HTH gives P(c0=0)=(1+1/√2)/2 rather than equal-weight fake averaging; partial condition c0=1 with independent c1 leaves q1 maximally mixed; full eight-register postselection gives probability 1/256 and one selected state. Reset never supplies a classical condition.
