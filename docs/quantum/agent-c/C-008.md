## DELIVERED: usable end-to-end product vertical slice

1. **Density instruments:** new public `DensityMatrix::{wire_probability,postselect,measure,reset_unobserved}`.
   A Z instrument samples **Tr(P rho)**, collapses to `P rho P / Tr(P rho)`,
   and consumes exactly one seeded SplitMix64 draw for each sampled instrument.
   A deterministic unobserved reset maps `rho -> |0><0|_q ⊗ Tr_q(rho)`
   and neither consumes a random draw nor exposes the hidden branch.
   A separate **observed reset** samples the outcome, corrects via X,
   and records the result; the distinction is both physically and
   operationally important. An exactly impossible postselection fails without
   mutating rho. **Caveat:** extremely subnormal physical probabilities may
   already have been rounded away in an f64 *density matrix* before selection;
   these are not recovered or claimed to be measurable.
2. **Real Rust dynamic mixed-state runner:** new `noisy_circuit.rs` public
   `NoisyCircuit::{execute_once,execute_shots}` with versioned metadata,
   9 gate families, idealized `NoiseChannel` (phase flip / amplitude damping),
   Z measurement into a bounded classical register, `Reset`,
   `ResetObserved`, and classical conditions on both gates and noise.
   One fresh density matrix per shot, one deterministic RNG stream across
   observed measurements/shots. Every instruction, **including a branch that
   will not be taken**, is validated before any shot. Includes explicit
   overflow, invalid alias/bit, uninitialized classical read and logical
   allocation-budget failures.
3. **New external binary (no consumer migration):**
   `aura-quantum-noisy-run` accepts `aura.quantum.noisy-request/1`
   via stdin and emits the independent `aura.quantum.noisy-result/1` JSON
   schema with per-shot classical bits and ordered instrument traces,
   deterministic histogram (classical MSB-first; `?` is unwritten),
   seed/engine/numeric precision provenance and explicit
   `evidence_class="simulation"` / `qpu_hardware_jobs=0`.
   For exactly one shot and <=4 qubits, `inspect_final_density=true`
   returns **all complex row-major density elements**, diagonal Born
   probabilities, trace and purity.
   Limitations: <=256KiB input, <=6 CLI qubits (Rust engine <=8), 32 classical
   bits, 1024 shots, 192 ops, 4,194,304 admitted matrix-work units,
   <=16MiB logical output request budget and encoded result.
   No hardware API or network code. Errors are versioned JSON **stderr**,
   nonzero exit, and no success stdout. Original pure JSON v1 binary and
   request schema remain byte-for-byte unchanged.
4. **Runnable consumers:** `examples/noisy_feedback.rs` actually runs a
   Bell pair with gamma=0.20 damping on q1, Z-measures q0, classically
   corrects q1, nonselectively resets q0 and measures q1. **Analytic residual
   excitation = gamma/2 = 0.10**, with 1024-shot declared 6-sigma check.
   Fixture files `noisy_bell_feedforward_v1.json` (256 shots) and
   `noisy_tomography_v1.json` (full 1-qubit density) are
   actually executed in dedicated CI, independently of the unit-test suite.
   Earlier pure Bell and static Qiskit fixtures remain active.
