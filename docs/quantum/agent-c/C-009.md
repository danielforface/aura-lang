## Product BEFORE → AFTER

**BEFORE:** both existing simulation representations require
exponential memory for arbitrary n-qubit states:
statevector O(2^n), density-matrix O(4^n). There was no fast representation
for large *Clifford/stabilizer* circuits, no stabilizer API and no dedicated
CLI. The earlier pure/noisy JSON protocols are not stabilizer backends.

**AFTER:** a genuinely separate **binary symplectic signed-Pauli tableau**
with 2n rows (n destabilizers + n stabilizers), word-packed X/Z bit vectors
and Hermitian Pauli signs, supports:

1. H/X/Y/Z/S/CX/CZ/SWAP Clifford gates with exact binary row transforms,
   including CNOT sign correction and Pauli multiplication relative to
   standard Y = i X Z; T is explicitly **UNSUPPORTED_NON_CLIFFORD** even in
   an unexecuted classical branch.
2. Computational-basis Z projective instruments: distinguish deterministic
   outcomes from 50/50 random outcomes, preserve tableau invariants when
   collapsing; impossible postselection leaves tableau unmodified.
3. Sampled Z reset + X correction with ordered trace (observable internal
   outcome), and classically guarded Clifford gates. SplitMix64 seed and
   RNG call-order are compatible with the existing pure reference subset.
   Unobserved nonselective reset is **not** represented: that belongs to
   the separately supported mixed-state density backend.
4. Explicit public Rust `StabilizerTableau` and
   `StabilizerCircuit::{execute_once,execute_shots}`, which return
   seed/engine/version/profile metadata, classical bits, instrument trace
   and optional final tableau. The Rust solver supports up to **256** qubits
   and has checked per-job work, shots, instruction and logical memory
   budgets (excluding OS RSS/allocator/caller copies).
5. A new standalone JSON command `aura-quantum-stabilizer-run`:
   strict schema `aura.quantum.stabilizer-request/1` →
   `aura.quantum.stabilizer-result/1`, simulated-only
   provenance, 2n signed-Pauli generator labels, histogram, instrument
   traces, and optional complete basis probabilities for a single-shot
   result with <=6 qubits. CLI bounds: 1..128 qubits, 1..1024 shots,
   <=512 instructions, <=64 classical bits, <=256KiB input,
   <=16MiB logical budget/encoded response and an explicit finite
   work-estimate admission. Errors yield JSON stderr / exit 2 and
   no fake hardware receipt. The previous pure and noisy JSON v1 schemas
   remain unchanged.
