## Science and reproducibility

- Phase-sensitive **interference**: `H Z H |0>=|1>`; intermediate Z phase alters later interference but not intermediate Z-basis probabilities. Non-Clifford `H T H |0>` has closed-form ideal probabilities `(2+sqrt(2))/4` and `(2-sqrt(2))/4` under floating-point tolerance `3e-11`.
- **Teleportation**: three-qubit `H(q1)`, `CX(q1,q2)`, `CX(q0,q1)`, `H(q0)`, computational measurements of q0/q1 followed by **test-harness** classical `X(q2)` when q1=1 and `Z(q2)` when q0=1. Input state is `sqrt(0.37)|0> + exp(i*0.43)*sqrt(0.63)|1>`, not just a computational basis state. All four Bell measurement outcomes appeared across 128 deterministic seeds; corrected q2 fidelity `|<input|output>|² = 1` within tolerance `3e-11`, allowing only global phase. Negative control: at least one branch without correction has fidelity below 0.95. This tests a circuit through library calls, **not implementation of a compiler/runtime dynamic-control language feature**.
- **Independent numerical cross-check**: `tests/dense_oracle.rs` generates full 8x8 gate action through textbook per-matrix-element multiplications, separately from the engine's in-place swaps/pairs. It compares every complex amplitude after 15 composed single/two-qubit gates (including all nine gate families), norm and non-basis input; tolerance `2e-11`. This is an independent *algorithmic* oracle inside the same toolchain, not a peer-reviewed proof or third-party implementation.
- **Statistical measurement**: prepared teleportation measurement register q0/q1 has each marginal `P(00)=P(01)=P(10)=P(11)=0.25`; the reference tests inspect analytic f64 sums and 4,096 seeded shots with absolute tolerance 0.035. Expected single-bin standard deviation under a multinomial sample is `sqrt(0.25*0.75/4096) ~= 0.00677`; tolerance is >5 standard deviations per bin. This is stochastic evidence with declared seed, *not exactly one quarter observed outcomes*.
- **Norm stress**: 10,000 successive H/H gate pairs on one qubit: bounded residual under `3e-11`; this does not certify arbitrarily long circuits.
- **Rare-event numeric policy**: `postselect` can condition on an amplitude that is nonzero in `f64` even when its squared Born probability underflows to a zero-valued `f64`. The separate `wire_probability` / `basis_probability` numeric accessors remain ordinary binary64 sums/squares and **cannot represent subnormal-underflowed probabilities reliably**. SplitMix64 samples only 53 bits of uniform mantissa, so ultra-rare events have no measurable support at this finite RNG precision. We do **not** interpret this as exact real-number simulation or certified error bounds.
