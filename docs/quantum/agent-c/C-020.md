# Agent C — C-020 | Bounded ideal-channel local tomography

**BEFORE→AFTER real product:** C-018/C-019 reports unconditioned final Hamiltonian mean, second moment, variance and final classical histogram. No callable API can expose actual reduced subsystem density matrices or distinguish a reduced mixed state before/after nonselective ideal measurements. New `execute_channel_tomography(circuit,selected_pairs,budget)` computes the **unconditional ideal channel final** 2×2 density for *every one of 1..8 wires*, and 4×4 density for **up to 16** requested distinct ascending wire pairs. Output includes `Tr(rho²)`, branch-mean reduced purity and their difference (branch-mixing gap), plus local Bloch X/Y/Z, final classical histogram, branch count, total Born mass and preflight work/memory accounting.

**Physics:** for each selected subsystem S, `rho_S = sum_b p_b Tr_not_S(|psi_b><psi_b|)`, with every representable physical `Measure/Reset/If` branch weighted by Born probability and classical register preserved. The common C-018 physics path `enumerate_channel` is reused — **there is no second measurement simulator**. `mean_branch_purity = sum p_b Tr(rho_{S|b}²)` and `branch_mixing_gap = mean_branch_purity - Tr(rho_S²) >= 0`. A Bell pair before measurement has local rho=I/2 with zero *branch* gap but a pure 4x4 pair rho (coherence 00↔11); after observing and forgetting a Z measurement, local rho remains I/2 while branch gap rises and pair off-diagonal 00↔11 is removed. This demonstrates why local mixedness is **not in general an entanglement measure** and why branch mixture gap is not an entanglement witness.

**Order:** global q0 LSB. For pair [a,b] with a<b, local pair basis index is bit(a)+2bit(b); matrix is 4x4 row-major Complex<f64>. `BlochY = -2 Im(rho01)` and X=2 Re(rho01), Z=rho00-rho11. 1-wire density trace=1, purity in [0.5,1]; pair purity in [0.25,1]; small numeric roundoff clamped only in disclosure-bound checks, no quantum truncation. No noisy hardware, QPU, mixed hardware observation, 128-qubit globally-entangled claim, formal proof or automatic Aura Core/QIR integration.

**Profile:** separate constrained dense ≤8 global qubits, ≤8 Measure+Reset operations/256 branches, ≤512 operations, ≤64 classical bits, up to 16 selected ascending nonduplicated pairs, ≤16 MiB logical memory and existing conservative work limit. Additional local matrix output reserve is charged *before* branching. Admission rejects invalid wire/pair/order/duplication/memory/resource gates. Old C-018 `channel-moments-request/1` and prior C-016/C-017 contracts are preserved.
