# Agent C — C-018 | Exact ideal-instrument quantum-channel moments

**BEFORE → AFTER.** Existing C-017 `moments/1` computes pure-state Pauli energy and variance on only one seeded trajectory. A dynamic mid-circuit Measure/Reset/If program requires a *different* channel average over physical instrument outcomes. New C-018 `execute_channel_moments(&Circuit, &[PauliTerm], budget)` exactly enumerates all representable nonzero branches within an explicit dense profile, retaining classical controls and weighted Born probabilities. It outputs unconditional mean, second moment, total variance, within-branch variance, between-branch variance and final classical-register distribution. Reset splits into two unobserved outcomes and conditionally applies X without writing the classical register.

**Mathematics.** For branch j, use p_j from Z projection and propagate a normalized |psi_j>. For real Hermitian H=sum cP, mean=sum p_j <psi_j|H|psi_j>, second=sum p_j ||H|psi_j>||² and variance=second-mean². Law of total variance: within=sum p_j Var(H|j), between=sum p_j (mean_j-mean)². Pauli Y phases are from the original complex Statevector gate. This is a deterministic ideal channel, not a noisy CPTP simulation, QPU observation, or proof of arbitrary-program equivalence.

**Strict bounded profile.** At most 8 dense qubits, 8 Measure+Reset operations, 256 branches, 512 instructions, 64 classical bits, 64 Pauli terms, |coefficient|<=10000, 16MiB max budget and 67,108,864 conservative work units. Admission charges up to 3 branch generations plus H|psi> scratch and histogram. A nonzero supported amplitude whose Born weight underflows to zero fails closed; no silent probability truncation. Finite f64 numerical/normalization checks remain, no mathematically certified error bound. No global 2^128 allocation. Existing 128q factorized *conditional* engine and all JSON schemas remain unchanged.

**Code/tests.** New C-only src/channel_moments.rs, tests/channel_moments.rs, example channel_moments_feedforward.rs. Real 3q Bell measurement with classical feedforward and hidden reset shows 4 final instrument histories, mean 0, variance 1, within 0/between 1. Tests separately check coherent superposition variance, observed measurement, reset, repeated-measurement correlation, noncommuting Pauli and fail-closed branch/width/memory/input semantics.
