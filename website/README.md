# Aura website

This directory is the public website for the Aura programming-language platform.

The website is intentionally aligned with the repository's public truth layer:

- `../PROJECT_STATUS.md`
- `../ARCHITECTURE.md`
- `../LANGUAGE_GUIDE.md`
- `../VERIFICATION_MODEL.md`
- `../TOOLCHAIN.md`
- `../ECOSYSTEM.md`

## Product positioning

Aura is presented as:

> **Aura 2026 Edition — an active, pre-stable proof-driven systems programming language and developer platform.**

The website must not silently upgrade targets or implementation work into stronger claims. In particular it does not claim a formally verified compiler, frozen stable v1.0 semantics, a production JIT, universal sub-200ms proofs or universal production Android support.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- MDX content via `next-mdx-remote`

The rebuilt visual system intentionally uses local/system font stacks and inline SVG symbols so the website has no runtime dependency on remote font delivery or a third-party icon package.

## Development

```bash
npm install
npm run dev
```

The `dev` and `build` scripts regenerate the Aura grammar and plugin documentation before starting/building Next.js.

## Production build

```bash
npm install
npm run lint
npm run build
```

## Documentation model

`content/docs/` is the source for `/docs/...` pages. `src/lib/docsNav.ts` groups the public navigation. Generated plugin docs remain generated by the repository scripts.

When documentation and implementation disagree, use this precedence:

1. current compiler implementation,
2. compact SDK reference (`../sdk/docs/reference.md`),
3. focused current verifier/protocol docs,
4. historical roadmap/design/completion documents.

## Downloads

Do not add a download CTA merely because the release tool can produce an artifact. A public download link should only be added when the corresponding file or release artifact is actually published and can be verified.

## Benchmarks

Do not publish illustrative benchmark numbers as product evidence. Performance claims require a reproducible benchmark artifact with commit, environment, workload, solver/toolchain configuration and methodology.
