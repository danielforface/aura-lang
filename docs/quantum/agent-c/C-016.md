# Agent C — C-016 | Analytic Pauli observables on factorized pure CPU states

**Production goal BEFORE → AFTER:** Previously Q28's factorized
simulator could query one basis probability or simulate shot counts,
but could not return analytic Pauli-string expectations over up to
128 global wires. A consumer interested in a Hamiltonian's
weighted `X/Y/Z` correlators faced 2^128 dense-vector expansion
or statistical sampling, even when the global state was a product
of fully entangled local factors.

Now `FactorState::expectation_pauli` computes each factor's
complex `⟨ψ_f|P_f|ψ_f⟩` using at most 2^10 amplitudes,
including physically correct Y = [[0,-i],[i,0]] phases,
and combines the factor contributions without truncation.
`FactorCircuit::execute_observables` processes a *single
actual seeded circuit trajectory*, then computes ≤64 bounded
real weighted Pauli energies without touching the quantum
state or consuming additional RNG. A strict new offline
`aura-quantum-observable-run` JSON request/result v1,
with q0-first Pauli string order, trace, weighted sum
and explicit CPU-only provenance, exposes the operation.

**Scientific scope:** Since actual mid-circuit Z measurements
and resets are sampled once, the analytic Pauli expectation
on the resulting *conditioned pure state* is not a
superoperator/mixed-branch average. This interface is
not a general-purpose VQE optimizer, a universal tensor
network/SVD engine, or formal equivalence and does not
use QPU hardware. Float rounding remains subject to
the numeric engine's finite `f64` accuracy; tensor
truncation is absent only in the supported factor profile.

**Bounds:** global qubits ≤128, factor width ≤10,
instructions ≤512, 1–64 terms, Pauli letters
only ASCII `I/X/Y/Z`, length = qubits, coefficient
finite and abs ≤10,000, explicit observable work
≤16,777,216 conservative units, input ≤256KiB,
output ≤16MiB, budget ≤16MiB and separate charged
term-output logical memory. No fake hardware/provider
fields, incomplete results or silently ignored
unreachable invalid conditional gates.

**Acceptance:** 128q 64 Bell pairs with one T gate
each, 192 actual instructions, five analytic
terms, energy `1.25 + 1/sqrt(2)`; complete dense
2–11q Pauli/Y phase parity, conditioned
Trace/Reset/Feedforward exact source parity,
invalid/overflow/unknown-field no-stdout
negative tests, external Qiskit 56 dynamic
cases ×6 Pauli terms (336 analytic checks)
plus 56 mutated negative controls and
independent 2q-to-128q factor witness.
The Qiskit reference conditions on the
*observed source trace*; it does not prove
unbiased stochastic sampling or formal
measurement-channel equivalence.
