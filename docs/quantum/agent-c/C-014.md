## BEFORE → AFTER observable user behavior

BEFORE: the C-013 `FactorState::apply` merged two
previously disjoint factors for *every* cross-factor CX/CZ,
including true identities CNOT(|0>, ψ), controlled X from |1>,
CZ with a known |0> and CX targeting X+ / X- eigenvectors.
A 128-wire circuit with H/CZ/CX/H of all independent
targets could exceed max component width=10, despite
never creating quantum entanglement. A globally sampled
`f64` pure state remained intractable in the 12-wire
dense backend and no exact decomposition was admitted.

AFTER: three mathematically sufficient, *bit-exact*
support/eigenstate predicates protect the cross-component
controlled operations:
1. Z-eigen control for CX: replace with local target X
   if |1>, otherwise no-op.
2. Entire target factor an X+/- eigenvector for CX:
   apply Z to control only for X−, else no-op.
3. Either operand Z-eigen for CZ: apply Z to
   opposite factor for |1>, else no-op.

Predicate is *strict coefficient equality*, not a
floating threshold, near-eigenstate estimate, SVD,
Schmidt compression, random postselection or tensor
truncation. General cross CX/CZ remains full checked
factor join with the original memory and width
preflight. Invalid self-target/unknown wires are
still rejected before shortcuts. A counted total
`product_preserving_two_wire_gates` appears as an additive
experimental output field, leaving the existing factorized
request schema, exact selected-backend provenance and all
other direct v1 engine schemas untouched.

**Actual product app:** `examples/factorized_classical_control_fanout.rs`
and two real JSON fixtures; 128q, **512 instructions**,
254 cross-factor controlled gates algebraically bypassing
joins, 128 singleton factors, exactly **4,096 logical
amplitude bytes** current/peak, final 128-bit all-one
basis probability ~1 and QPU=0. The endpoint is still
an *untruncated pure product* f64 CPU state, not
generic 128q coherent entanglement.
