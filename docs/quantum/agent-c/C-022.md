# Agent C — C-022 | Additive CPTP noise models on existing DensityMatrix

**Production BEFORE→AFTER.** Q28 already includes a working bounded density engine and noisy-request/1 dynamic seeded circuit with PhaseFlip, AmplitudeDamping, Z measurement, Reset, classical feedback and full inspectable final density. C-022 adds three *distinct physical noisy CPTP maps* to those existing C-owned APIs: PhaseDamping(gamma), Depolarizing(probability), and arbitrary single-wire PauliMixture(p_x,p_y,p_z). All are callable as direct `DensityMatrix::apply_noise(NoiseChannel)`, dynamic `NoisyInstruction::Noise` or conditional `NoisyAction::Noise`, and via existing strict experimental `aura.quantum.noisy-request/1` CLI. No duplicate engine, no new shared ABI, and no change to previous JSON schema/fields; only new allowed `channel.kind` values.

**Exact mathematical conventions.** (1) PhaseDamping(gamma) Kraus K0=diag(1,sqrt(1-gamma)), K1=sqrt(gamma)|1><1|: populations remain unchanged and target-bit offdiagonal coherences multiply sqrt(1-gamma). gamma=1 is complete dephasing, gamma=0 identity. This is NOT `PhaseFlip(0.5)` for general gamma, although they coincide at complete dephasing. (2) Depolarizing(probability=p) explicitly denotes **the probability of a nonidentity Pauli error**: E(rho)=(1-p)rho+(p/3)(XrhoX+YrhoY+ZrhoZ). p=0.75 completely depolarizes a single qubit; p=1 gives Bloch contraction -1/3 and remains CPTP, not identity. (3) PauliMixture: E(rho)=pI rho + p_x XrhoX + p_y YrhoY + p_z ZrhoZ, pI=1-(p_x+p_y+p_z). Each p finite in [0,1], sum≤1. Matrix updates are performed using a disjoint four-index (target row/column) block to account for coherences with all other qubits and Pauli Y conjugation correctly, without a new density buffer. Existing C-owned `NoiseChannel::validated_qubit` serves as single fail-closed parameter validation authority in *both* direct `apply_noise` and `NoisyCircuit::preflight` including untaken If. Invalid weight/sum/basis fails before mutation or shots. All channels are CPTP in exact arithmetic; f64 runtime trace/Hermiticity checks are empirical, not proof of certified positive-semidefinite numerical error.

**Limits and scope.** Existing density profile up to 8 qubits; noisy-request/1 wrapper up to 6, ≤192 operations, ≤1024 shots, ≤4,194,304 charged matrix-work units and ≤16MiB logical budget. Inspecting full final density currently further limits ≤4 qubits with exactly one shot. Existing measurement/reset is seeded/conditioned observation, not unconditioned channel averaging. External QPU/noise calibration, hardware error rates, distributed or globally entangled 128-qubit noise are unsupported and never claimed. This is Q28-007 additive implementation; no actual device characterization.

**Tests/evidence.** Real source tests check Bell 2q coherence removal vs local populations, sqrt(1-gamma) phase damping, p=.75 fully mixed, p=1 1/3:2/3 split, complex Y and asymmetric p_x/p_y/p_z, arbitrary 2q density equality against equivalent symmetric Pauli mixture, dynamic adaptive If, invalid/NaN/out-of-bound/weight sum/untaken branches. Standalone CLI fixture + real subprocess tests and runnable example; pinned Qiskit independent Kraus state parity will compare full real CLI density, purity and trace with fail-closed poison/invalid contract checks. Prior C-016..021 Qiskit gates and Rust regression preserved.
