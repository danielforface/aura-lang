## Objective and method

C-002 repaired scale-first conditional normalization and left 20/20 Rust tests passing. C-003 deliberately does **not** broaden the engine's API or claim an unobserved defect: this is a **test-first assurance-only increment**, with no fabricated RED. It adds two independent styles of oracle:

1. Numerical matrix comparison for **128 deterministic circuits**. For each of four widths `n=1..4`, generate 32 independent rich complex input vectors, each with 63 gates; **8,064 gate applications**, matching all live amplitude components after each step. The gate families are H/X/Y/Z/S/T/CNOT/CZ/SWAP. Operand selection and initial amplitudes use test-only **Xorshift64***, independent of the simulator's **SplitMix64** shot RNG, but both are pseudo-random deterministic fixtures. Each gate is independently represented by matrix entries and dense multiplication, unlike the implementation's in-place pair operations, bit swaps and phase flips. Tolerance **2e-11 absolute per real/imag component** and per-state norm (not a certified analytical bound). The independent oracle *shares* Rust f64 arithmetic and reference gate definitions; it is not an external third-party quantum framework or formal proof engine.

2. **Physics-inspired metamorphic properties and explicit negative controls**:
   - A two-qubit state with amplitudes `1e-300 * 0.6exp(0.37i)` and `1e-300 * 0.8exp(-1.13i)` in the selected q0=1 subspace. Ordinary f64 square probabilities underflow to 0; conditional projection retains the nonzero complex relative phase and 0.6/0.8 normalized magnitudes. Test tolerance **5e-13**.
   - Minimum positive f64 subnormal `f64::from_bits(1)` in both real and imaginary coordinates, producing normalized `(1+i)/sqrt(2)` after conditioning. Subsequent truly-zero support fails without corrupting the state.
   - Order independence for compatible computational-basis projectors on distinct wires, idempotent repeated postselection and repeated measurement; impossible/invalid operations preserve amplitudes, invalid measurement does not advance the RNG state.
   - Global complex phase rotation `exp(0.71 i)` alters amplitudes, not Born probabilities or identical-seed shot results, for a genuine non-basis three-qubit circuit.
   - Independently implemented one-wire partial trace computes reduced density matrices. A product state has reduced purity `Tr(rho^2)=1`, while the single-wire reductions of Bell and three-qubit GHZ have `rho=I/2` and purity `1/2`. Mutation-sensitive negative control omits a GHZ entangler and checks q2 remains separable (purity 1).
   - For Bell `(|00>+|11>)/sqrt(2)`, direct amplitude correlators give `<XX>=+1`, `<YY>=-1`, `<ZZ>=+1`; the algebraic `sqrt(2)*(<XX>+<ZZ>)=2sqrt(2)` matches ideal CHSH settings. **This is not a rotated-basis measurement experiment or loophole-free Bell test on actual hardware.**
   - Golden SplitMix64 u64 sequence for seed 0: `e220a8397b1dcdaf`, `6e789e6aa1b965f4`, `06c45d188009454f`, `f88bb8a8724c81ec`, `1b39896a51a8749b`. These test the exact existing RNG algorithm, not true randomness.

## Scientific and security limits

- All claims are about finite bounded **pure-state f64 simulation**, not universal mathematical quantum correctness, independent external certification, formal equivalence, QIR/OpenQASM interop, physical QPU observations, noise/QEC or execution permissions.
