## Production BEFORE → AFTER

Before: new C-012 factor-product engine could simulate 128 non-Clifford *disjoint* Bell/T pairs, but after measuring one wire inside a multiwire factor it left the entire (mathematically separable) projected factor joined. Sequential entangle→measure→classical reset to reuse a single live wire on 11+ fresh targets was rejected by the **10-wire connected-factor cap**, even though the physics after each observed projective Z outcome is a product state.

After: `src/factorized.rs` uses the original single seeded projective measurement, then safely extracts the measured coordinate **as a fresh one-qubit factor** with the exact complex *conditional* amplitudes of the remainder. Measured wire can attach to subsequent independent wires. No second RNG draw, fake clone, loss of classical outcome, float threshold for separability, SVD or Schmidt truncation. Global state still decomposes into a product of numeric local components; fully connected 128q T is still UNSUPPORTED.

A replacement is built while retaining original state until commit; temporarily old + new statevectors are included in the same checked **logical memory budget** as existing factor joins. If budget or fallible memory allocation prevents split, the physically correct collapsed original factor is kept. The underlying numeric error is still f64, not formally bounded by `NORM_TOLERANCE`. Single-shot factors remain inspectable. Two additive experimental JSON result-only counters report **actual** projection splits vs budget-deferred eligible attempts; original factorized input schema and all other four direct engine schemas unchanged, original complete auto-dispatch engine result preserved.
